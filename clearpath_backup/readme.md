# Humble to Jazzy migration plan for Jackal

## What's backed up before the upgrade

| **File**                                           | Description                                                                                                                                                          |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/etc/netplan/*`                                   | Has static IP and router configs (Not hosted on this repository)                                                                                                     |
| `/etc/clearpath/robot.yaml`                        | Has robot configuration stored related to the platform's URDF, Realsense and IMU sensor configs.                                                                     |
| `/etc/clearpath/*`<br>`/etc/ros/humble/clearpath*` | `robot.yaml` is used to autogenerate everything else in these folders. However, we're keeping  a copy of them just in case the autogenerated configs miss something. |
| `~/colcon_ws/src/ona01_jackal`                     | `robot.yaml` uses this package for adding sensors to the autogenerated URDF                                                                                          |
| `~/amd_ws/src/*`                                   | All packages in this workspace already exist on GitHub repos and can automatically install from `deps.repos`, still backing up if needed                             |

## Upgrade process

### Operating System

- Download the [Clearpath's Jazzy image](https://packages.clearpathrobotics.com/stable/images/2.0.0/) and prepare a bootable flash drive
- Install the new Operating system following the [instructions](https://docs.clearpathrobotics.com/docs/ros/installation/robot/#operating-system) from Clearpath
- - Copy these files
	- `robot.yaml` file to `/etc/clearpath/` folder
	- and `ona01_jackal` package to `colcon_ws/src` (build this workspace before proceeding)
- Then run the `clearpath_computer_setup.sh` script to install Clearpath software packages and configuration for Jackal

### Motor controller firmware

- Get a micro-USB cable
- Follow their [instructions](https://docs.clearpathrobotics.com/docs/ros/installation/robot/#firmware-update) to upgrade

Restart the computer and the robot should now be in factory state!

### Restoring a few things from Humble setup

- Restore the network config by copying the `50-clearpath-bridge.yaml` and `60-wireless.yaml`
- Create `amd_ws`, clone the [demos](https://github.com/open-navigation/opennav_amd_demonstrations/tree/main) repo, install the dependencies and build the workspace
- Disable Clearpath services as described in the honeybee [`docs`](https://github.com/open-navigation/opennav_amd_demonstrations/blob/main/docs/disable_clearpath_services.md)
	- And just add the `robot_bringup.service` to `systemd` routine
- Make sure CycloneDDS is used and is configured according to this [article](https://www.stereolabs.com/docs/ros2/dds-and-network-tuning)
- Either reboot or just start the `robot_bringup.service` and see how it does...
